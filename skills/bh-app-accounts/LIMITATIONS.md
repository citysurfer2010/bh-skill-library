# Benutzerverwaltung: Bekannte Grenzen

- Dieser Skill ist eine Anleitung, kein fertiger Baustein. Der Code entsteht je App.
- Der Wächter prüft Geheimnisse und freiliegende Dateien, aber nicht die Logik der Anmeldung.
- Daten liegen im Container des Users, eine Sicherung richtet die Plattform dafür nicht automatisch ein.
- Eine Sicherheitsprüfung durch einen Menschen ersetzt das nicht, wenn echte Kundendaten verarbeitet werden.
