# Business Logic: BH Agent Actions

- Aktionen, die über verschiedene Zugänge hinweg gelten, werden hier gebündelt: als Rezepte und als Funktionen im MCP-Server. Quelle: Matti, 09.11.2026.
- Die Fach-Skills bleiben rein und machen nur ihr eigenes System. Das Zusammenspiel steht hier.
- Was etwas Echtes auslöst (Heizung, Einladungen), läuft nur auf ausdrücklichen Wunsch; mit Gästen wird vorher nachgefragt.
- Status je Aktion: `aktiv`, `teilweise` oder `geplant`.
